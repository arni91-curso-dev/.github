# Mis cursos de desarrollo

Ejercicios y proyectos de los cursos que hago para aprender. Mis proyectos personales están en mi perfil, [arni91](https://github.com/arni91).

## Curso de desarrollo con IA (2026)

Programar dirigiendo agentes de IA con método: contexto (AGENTS.md, memoria, skills, MCP) y Spec-Driven Development (constitución, spec en EARS, plan, tareas, implementación con tests primero y validación).

- [MyStudyDiary](https://github.com/arni91-curso-dev/MyStudyDiary): diario de estudio con racha de días seguidos, estadísticas de la semana y del mes, y mapa de calor de 12 semanas. HTML, CSS y JavaScript sin dependencias, con 47 tests (`node --test`) y todo el proceso SDD en `specs/`.

## Bootcamp de desarrollo web en Ironhack (2025)

Todos los ejercicios y proyectos que hice en el bootcamp de desarrollo web de Ironhack, entre abril y septiembre de 2025.

En el backend trabajé con Java, Spring Boot, JPA/Hibernate, MySQL, JUnit y MockMvc. En el frontend, con React, Vite, React Router y Supabase.

### Proyectos más completos

- [InOut](https://github.com/arni91-curso-dev/InOut): API para controlar los fichajes de los empleados, con login por JWT. Java, Spring Boot, Spring Security y MySQL.
- [M3_project](https://github.com/arni91-curso-dev/M3_project): app de fichajes para restaurantes. Los trabajadores fichan la entrada y la salida, y los administradores gestionan los fichajes y el personal. React y Supabase.
- [IronBattle-grupo3](https://github.com/arni91-curso-dev/IronBattle-grupo3): simulador de batallas por turnos entre un guerrero y un mago, hecho en grupo. Java.
