# Bootcamp de desarrollo web — Ironhack (2025)

Ejercicios, labs y proyectos que hice durante el bootcamp de Ironhack, de abril a septiembre de 2025. Mis proyectos personales están en mi perfil: [@arni91](https://github.com/arni91).

**Stack trabajado:** Java · Spring Boot · JPA/Hibernate · MySQL · JUnit y MockMvc · React · Vite · React Router · Supabase

## Proyectos destacados

| Proyecto | Qué es | Tecnologías |
|---|---|---|
| [InOut (backend)](https://github.com/arni91-curso-dev/InOut) | Sistema de control de fichajes de empleados: API REST con autenticación JWT | Java, Spring Boot, Spring Security, MySQL |
| [InOut (fullstack)](https://github.com/arni91-curso-dev/M3_project) | App de fichajes para restaurantes: los trabajadores fichan y los administradores gestionan fichajes y personal | React, Supabase |
| [IronBattle](https://github.com/arni91-curso-dev/IronBattle-grupo3) | Simulador de batalla RPG entre un guerrero y un mago (proyecto en grupo) | Java |
